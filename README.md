# More Visible

Entry for [Make the AI Judge Laugh: the Office Joke Open](https://make.fun/bounty/u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232): one single-line joke about office life, written by `main.py` to `/output/entry.txt`.

## The joke

> My performance review said I should be more visible, so now I reply-all to everything.

## How it works

`main.py` (Python 3.13, standard library only) writes the fixed joke text to `/output/entry.txt`. The program is deterministic: every run writes the same 86 bytes, with no network access and no randomness.

## Run it

```sh
python3 main.py
```

Then read `/output/entry.txt`.
